# 🚀 Bootcamp em Machine Learning — Escola Atlântico Avanti

Este repositório reúne as **atividades, desafios práticos e projetos desenvolvidos ao longo do Bootcamp em Machine Learning**, oferecido pela **Escola Atlântico Avanti**, com foco na aplicação prática de conceitos de estatística, programação, ciência de dados e aprendizado de máquina.

O objetivo principal deste repositório é documentar minha evolução técnica, consolidar conhecimentos e construir um portfólio organizado para futuras oportunidades acadêmicas e profissionais.

---

## 📚 Sobre o Bootcamp

O bootcamp aborda fundamentos e aplicações práticas em:

- Programação em Python para Machine Learning    
- Limpeza, tratamento e exploração de dados (EDA)  
- Visualização de dados  
- Aprendizado de Máquina (Machine Learning)  
- Construção e avaliação de modelos preditivos  
- Boas práticas de projetos ML
